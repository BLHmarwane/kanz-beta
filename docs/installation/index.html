Kanz Beta

Installer la bêta.

Prévois quelques minutes pour télécharger et ouvrir Kanz pour la première fois.

Télécharger la bêta sur GitHub ↗

Voir toutes les versions sur GitHub

  1. Télécharge le ZIP.

    Le bouton de téléchargement ouvre le ZIP dans ton navigateur. Sur la page des versions GitHub, le ZIP se trouve dans les fichiers de chaque version, sous Assets.

    Lancer le téléchargement avec le Terminal

    Cette commande ouvre le lien du ZIP dans ton navigateur par défaut.

    /usr/bin/open 'https://github.com/BLHmarwane/kanz-beta/releases/download/v0.1.0-beta.2/Kanz-Beta-0.1.0-2.zip'

  2. Déplace l’application.

    Dans le Finder, ouvre Téléchargements et double-clique sur le ZIP. Déplace ensuite Kanz Beta.app dans Applications. Si une copie de la bêta existe déjà, choisis celle que tu veux conserver avant de continuer.

    Déplacer l’app avec le Terminal

    Après extraction du ZIP, cette commande déplace l’app vers le dossier Applications de ton compte. Une copie existante est conservée.

    mkdir -p "$HOME/Applications" && /bin/mv -nv "$HOME/Downloads/Kanz Beta.app" "$HOME/Applications/"

  3. Ouvre Kanz Beta.

    Double-clique sur Kanz Beta.app. La bêta n’est pas notarisée par Apple et macOS peut bloquer le premier lancement. Si tu as téléchargé le ZIP depuis la page GitHub de Kanz et que tu souhaites continuer, ouvre Réglages Système → Confidentialité et sécurité, descends jusqu’à Sécurité et clique sur Ouvrir quand même. Confirme ensuite l’ouverture.

    Consulter l’aide Apple ↗

Ton Mac doit avoir

Une puce Apple et macOS 14 Sonoma ou une version ultérieure.

Tu peux vérifier dans le menu Pomme → À propos de ce Mac.
